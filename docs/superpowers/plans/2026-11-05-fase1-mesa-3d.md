# Fase 1: mesa 3D, cámara por scroll y carta de entrada 3D (plan de implementación)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Poner la mesa 3D fija detrás de toda la página, mover la cámara con el scroll entre paradas y llevar la carta de entrada (cinco principios + volteo al Joker) a 3D sobre el paño.

**Architecture:** Un `<Canvas>` fijo a pantalla completa detrás del `<main>`. La lógica que se puede probar sin WebGL vive en módulos puros (`recorrido.js`, `fisica.js`) con tests de Vitest; los componentes de r3f solo leen esos módulos y dibujan. El HTML de la entrada (contador, aviso, botón accesible) habla con la escena por un store de zustand. El resto de la página (mano, Máquina, Joker de la v1) sigue en HTML encima de la mesa hasta las fases siguientes.

**Tech Stack:** React 19, Vite 8, three 0.171, @react-three/fiber 9, zustand 5, Vitest 3, playwright-core (solo verificación, en el scratchpad).

**Spec:** `docs/superpowers/specs/2026-11-05-portafolio-baraja-design.md` (secciones "La escena", "Paradas" punto 1, "Celular primero", "Accesibilidad").

## Global Constraints

- Textos visibles: sin guion largo (`—`); inglés británico en la versión `en`; todo texto nuevo va en `src/content/textos.js` como `{ es, en }`.
- Commits sin `Co-Authored-By` ni atribución de IA.
- Paleta: paño vino oscuro `#3a1416`, madera `#4a2e1c`, marfil `#efe7d6`, rojo naipe `#b3302a`, luz de lámpara `#ffd9a0`; dorado `#ffcc4d` solo para la Máquina.
- Celular primero: dpr máximo 1.5 si `(pointer: coarse)`; sin sombras en tiempo real (manchas de sombra con textura radial).
- Un solo `<Canvas>` para la mesa.
- `prefers-reduced-motion: reduce`: cámara salta entre paradas, sin física ni temblor; un toque voltea la carta.
- Sonidos solo con `src/lib/sonido.js` (`sonar`, `fichas`).
- Sin WebGL: se renderiza la entrada plana de la v1 (`src/components/entrada/Entrada.jsx`).

```js
import { describe, expect, it } from 'vitest'
import { PARADAS, camaraEn, progresoDeScroll } from './recorrido'

describe('progresoDeScroll', () => {
  const inicios = [0, 800, 2400, 3400]
  it('vale 0 arriba del todo', () => expect(progresoDeScroll(0, inicios)).toBe(0))
  it('vale 1 justo en la mano', () => expect(progresoDeScroll(800, inicios)).toBe(1))
  it('interpola a mitad de camino', () => expect(progresoDeScroll(1600, inicios)).toBeCloseTo(1.5))
  it('no pasa de la última parada', () => expect(progresoDeScroll(9999, inicios)).toBe(3))
  it('no baja de 0 con scroll negativo (rebote de iOS)', () => expect(progresoDeScroll(-120, inicios)).toBe(0))
})

describe('camaraEn', () => {
  it('en una parada exacta devuelve sus valores', () => {
    expect(camaraEn(1, false, false).pos).toEqual(PARADAS[1].pos)
  })
  it('usa los valores móviles en celular', () => {
    expect(camaraEn(0, true, false).pos).toEqual(PARADAS[0].posMovil)
  })
  it('suaviza entre paradas (smoothstep): a 0.25 avanza menos de un cuarto', () => {
    const a = PARADAS[0].pos[1]
    const b = PARADAS[1].pos[1]
    const y = camaraEn(0.25, false, false).pos[1]
    expect(Math.abs(y - a)).toBeLessThan(Math.abs(b - a) * 0.25)
  })
  it('con movimiento reducido salta a la parada más cercana', () => {
    expect(camaraEn(1.4, false, true).pos).toEqual(PARADAS[1].pos)
    expect(camaraEn(1.6, false, true).pos).toEqual(PARADAS[2].pos)
  })
})
```

### Task 2: Física de la carta y principios

**Files:**
- Create: `src/escena/carta/fisica.js`
- Test: `src/escena/carta/fisica.test.js`

**Interfaces:**
- Produces:
  - `crearCarta(): EstadoCarta` con `{ x, z, vx, vz, rot, w, k, angK, q, angQ, sostener: null|{inicio, fase:'carga'|'pausa'|'hecho'}, pausaHasta, temblor, lanzada }` (metros, m/s).
  - `paso(c: EstadoCarta, dt: number, ahora: number, limites: { x: number, z: number }): Evento[]` muta `c` y devuelve eventos `{ tipo: 'rebote', impacto: number, normal: [nx, nz], punto: [x, z] } | { tipo: 'estallido' } | { tipo: 'pausa' }`.
  - `principiosDe(eventos: Evento[], c: EstadoCarta): Array<'estirar'|'inercia'|'sacudida'|'hitstop'>`.
  - `clasificarSoltar(duracion: number, arrastro: boolean, fase?: string): 'voltear'|'lanzar'|'nada'`.
  - Constantes: `T_TOQUE = 0.22`, `T_CARGA = 0.45`, `T_ESTALLA = 1.3`, `PAUSA = 0.15`, `IMPACTO_SACUDIDA = 3.2` (m/s), `IMPACTO_REBOTE = 0.45` (m/s), `ROCE = 2.4`, `REBOTE = 0.55`, `DT_MAX = 0.033`.

Es la misma física de la v1 (`src/components/entrada/Entrada.jsx`, bucle `paso`) pasada de píxeles a metros sobre el plano XZ; los umbrales en m/s de arriba sustituyen a los de píxeles.

- [ ] **Step 1: Escribir los tests**

```js
import { describe, expect, it } from 'vitest'
import { crearCarta, paso, principiosDe, clasificarSoltar, IMPACTO_SACUDIDA, T_ESTALLA, PAUSA } from './fisica'

const L = { x: 0.5, z: 0.3 }

describe('vuelo libre', () => {
  it('el roce frena la carta', () => {
    const c = crearCarta(); c.vx = 1
    paso(c, 0.016, 0, L)
    expect(c.vx).toBeLessThan(1)
    expect(c.x).toBeGreaterThan(0)
  })
  it('rebota en el borde invirtiendo y amortiguando la velocidad', () => {
    const c = crearCarta(); c.x = 0.49; c.vx = 2
    const ev = paso(c, 0.016, 0, L)
    expect(c.x).toBeLessThanOrEqual(0.5)
    expect(c.vx).toBeCloseTo(-2 * 0.55 * Math.exp(-2.4 * 0.016), 2)
    expect(ev[0]).toMatchObject({ tipo: 'rebote', normal: [1, 0] })
  })
  it('dt enorme se acota (pestaña que vuelve de segundo plano)', () => {
    const c = crearCarta(); c.vx = 1
    paso(c, 30, 0, L)
    expect(Math.abs(c.x)).toBeLessThanOrEqual(L.x)
    expect(c.x).toBeLessThan(0.05)
  })
  it('limitar tras cambiar límites (girar el celular) la devuelve al paño', () => {
    const c = crearCarta(); c.x = 0.5; c.z = 0.3
    paso(c, 0.016, 0, { x: 0.2, z: 0.15 })
    expect(c.x).toBeLessThanOrEqual(0.2)
    expect(c.z).toBeLessThanOrEqual(0.15)
  })
})

describe('principios', () => {
  it('un rebote fuerte es sacudida; uno suave tras lanzar es inercia', () => {
    const c = crearCarta(); c.lanzada = true
    expect(principiosDe([{ tipo: 'rebote', impacto: IMPACTO_SACUDIDA + 0.1 }], c)).toContain('sacudida')
    expect(principiosDe([{ tipo: 'rebote', impacto: 0.8 }], c)).toEqual(['inercia'])
  })
  it('estirar se detecta con k > 0.13 mientras se arrastra', () => {
    const c = crearCarta(); c.k = 0.2; c.arrastrando = true
    expect(principiosDe([], c)).toContain('estirar')
  })
  it('mantener apretada: pausa en T_ESTALLA y estallido tras PAUSA', () => {
    const c = crearCarta(); c.sostener = { inicio: 0, fase: 'carga' }
    expect(paso(c, 0.016, T_ESTALLA, L).map((e) => e.tipo)).toContain('pausa')
    expect(paso(c, 0.016, T_ESTALLA + PAUSA + 0.01, L).map((e) => e.tipo)).toContain('estallido')
    expect(principiosDe([{ tipo: 'estallido' }], c)).toContain('hitstop')
  })
})

describe('clasificarSoltar', () => {
  it('toque corto voltea', () => expect(clasificarSoltar(0.1, false)).toBe('voltear'))
  it('arrastre lanza', () => expect(clasificarSoltar(0.5, true)).toBe('lanzar'))
  it('soltar a media carga no hace nada', () => expect(clasificarSoltar(0.8, false, 'carga')).toBe('nada'))
  it('tras el estallido no voltea', () => expect(clasificarSoltar(1.6, false, 'hecho')).toBe('nada'))
})
```
