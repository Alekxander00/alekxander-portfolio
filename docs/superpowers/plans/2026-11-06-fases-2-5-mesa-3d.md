### Task 1: Disposición de la mano y texturas de naipe

**Files:** Create `src/escena/mano/disposicion.js`, `src/escena/mano/disposicion.test.js`, `src/escena/carta/naipe.js`

**Interfaces:**
- Produces:
  - `posicionesMano(n: number, movil: boolean): Array<{ x: number, z: number, rotY: number, escala: number }>` en metros sobre el paño. Escritorio: abanico de una fila centrado en `z = 0.42`, separación 0.155 m, giro de ±0.06 rad por carta desde el centro. Móvil: rejilla de 2 columnas (x = ±0.1) y filas cada 0.27 m empezando en `z = 0.12`. La primera carta (el As) lleva `escala` 1.25; las demás 1.
  - `ANCHO_CARTA = 0.18`, `LARGO_CARTA = 0.252`.
  - `texturaProyecto(p, t): Promise<THREE.CanvasTexture>` (índice valor/palo en dos esquinas con el color del palo, centro con la imagen del proyecto recortada a lo ancho o pips/figura si no hay imagen, título abajo en Gloock) y `texturaNaipe(valor, palo): THREE.CanvasTexture` (pips o figura, como `CaraNaipe`).

- [ ] **Step 1: Tests**

```js
import { describe, expect, it } from 'vitest'
import { posicionesMano, ANCHO_CARTA } from './disposicion'

describe('posicionesMano', () => {
  it('da una posición por carta', () => expect(posicionesMano(8, false)).toHaveLength(8))
  it('en escritorio las cartas no se tapan más de un 20 %', () => {
    const p = posicionesMano(8, false)
    for (let i = 1; i < p.length; i++) expect(p[i].x - p[i - 1].x).toBeGreaterThan(ANCHO_CARTA * 0.8)
  })
  it('en escritorio el abanico está centrado', () => {
    const p = posicionesMano(8, false)
    expect(p[0].x + p[7].x).toBeCloseTo(0)
  })
  it('en celular son dos columnas que caben en 0.42 m de ancho', () => {
    const p = posicionesMano(8, true)
    expect(new Set(p.map((c) => c.x)).size).toBe(2)
    expect(Math.max(...p.map((c) => Math.abs(c.x))) + ANCHO_CARTA / 2).toBeLessThan(0.21)
  })
  it('el As es más grande', () => expect(posicionesMano(8, false)[0].escala).toBeGreaterThan(1))
  it('con un filtro de 1 carta, queda en el centro', () => expect(posicionesMano(1, false)[0].x).toBe(0))
})
```

### Task 2: La mano en 3D

**Files:** Create `src/escena/mano/ManoMesa.jsx`, `src/components/mesa/ManoHTML.jsx`, `src/lib/con3D.jsx`; Modify `src/escena/estado.js`, `src/escena/Escena.jsx`, `src/escena/recorrido.js` (parada mano), `src/App.jsx`.

**Interfaces:**
- Consumes: `posicionesMano`, `texturaProyecto` (Task 1); `proyectos`, `PALOS`; `useEscena`.
- Produces:
  - Store: `palo: string|null`, `setPalo(p)`, `resaltada: string|null` (id con foco o hover), `setResaltada(id)`, `abrir: (id) => void` (lo registra `App`), `abierta: string|null`, `setAbierta(id)`.
  - `<ManoMesa />`: un mazo en `[0.62, 0, 0.55]`; las cartas salen de él la primera vez que el progreso del scroll pasa de 0.55, con 0.07 s entre carta y carta (sonido `aterrizar`).   - Parada `mano`: escritorio pos `[0, 0.85, 1.05]` mira `[0, 0, 0.38]`; móvil pos `[0, 1.35, 0.95]` mira `[0, 0, 0.55]`.
  - `Con3DProvider value={con3D}` y `useCon3D()`.
  - `App`: con `con3D`, `ManoHTML` en lugar de `Mesa`; al abrir/cerrar un caso, `setAbierta` y `setPausada(abierta && con3D)`.
